# 오픈스페이스 알박기 감지 시스템

한양대 ERICA 융합교육관 스터디룸 14개(72석)에서, 짐만 두고 30분 넘게 자리를 비우는 알박기를 감지해 문 앞 표시등으로 알려 주는 프로젝트입니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| [기획/PRFAQ.md](기획/PRFAQ.md) | 6 Pager PR/FAQ (프로젝트 기본 정보, 보도자료, 외부·내부 FAQ) |
| [기획/현장사진_YOLO테스트](기획/현장사진_YOLO테스트) | 직접 찍은 스터디룸 사진에 사전학습 YOLO를 적용한 결과 (사람 0명, 가방·노트북만 검출) |
| [code](code) | 좌석 지정(ROI)과 알박기 판정 코드 |

## 판정 규칙 (기획 최종안)

| 표시등 | 상태 | 학생 행동 |
|---|---|---|
| 🔴 빨강 | 사람 있음 | 사용 중 |
| 🟡 노랑 | 사람 없음, 30분 미만 | 짐에 손대지 않음 |
| 🟢 초록 | 사람 없음, 30분 이상 | 짐을 룸 앞 회색 바구니로 옮기고 사용 |

> 참고: `code` 폴더는 기획 초기 버전(좌석 단위, 최근 2시간 재석 비율 10% 기준)으로 작성되어 있습니다. 기획 최종안(룸 단위, 30분 연속 부재, 3색 표시등)에 맞춘 수정이 필요합니다.
