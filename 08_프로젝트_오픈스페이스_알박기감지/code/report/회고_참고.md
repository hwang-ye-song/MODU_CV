# 회고 참고: 막혔던 부분과 해결

| 막힌 부분 | 원인 | 해결 |
|---|---|---|
| 꼼수(5분씩 들르기) 테스트가 실패함 | 판정은 맞았지만(약 135분에 반납대상), 그 뒤 주인이 돌아오자 "반납대상 자리에 앉은 새 이용자"로 보고 기록을 초기화해서, 마지막 시점의 상태만 본 테스트가 통과하지 못함 | 마지막 상태 대신 "부재 중에 반납예정·반납대상이 한 번이라도 떴는지"를 확인하도록 테스트를 수정 |
| 빈자리로 바뀐 이벤트의 재석 비율이 0으로 기록됨 | 빈자리가 되는 순간 세션 기록을 지운 다음 비율을 계산함 | 갱신 직전 값을 저장해 두었다가 빈자리 전환 때는 그 값을 기록 |
| 좌석 라벨이 상단 요약 바에 가려짐 | 좌석 영역이 화면 맨 위에서 시작하면 라벨 위치가 요약 바와 겹침 | 요약 바를 먼저 그리고, 라벨은 요약 바 높이 아래에서 시작하도록 수정 |
| 판정 로직 테스트가 47초나 걸림 | 재석 기록을 매 프레임 저장해서, 2시간이면 좌석당 수만 개를 매번 다시 합산함 | 사람 있음/없음이 바뀌는 시점만 저장 → 0.16초 (실제 운영 시 CPU 부담도 줄어듦) |
| `.bat` 파일 경로가 `srcoi_editor.py`로 깨짐 | 셸의 `printf`가 `src\roi`의 `\r`을 줄바꿈 문자로 해석함 | 파일을 직접 작성한 뒤 줄 끝만 CRLF로 변환 |
| 실행 bat에서 `FileNotFoundError: seats.json` 발생 ([캡처](images/seats_json_없음_오류.png)) | 좌석 지정(1번)을 건너뛰고 감지 실행(2번)을 먼저 실행함. 처음 고친 bat은 한글 echo가 괄호 블록 안에 있어서 `chcp 65001` 이후 cmd가 줄을 잘못 읽고 `else was unexpected` 오류를 냄 | `seats.json`이 없으면 bat이 좌석 지정 화면을 먼저 열도록 수정. bat 파일은 영어로만 쓰고 한글 안내는 파이썬에서 출력. `run.py`도 파일이 없으면 해결 방법을 안내 |
