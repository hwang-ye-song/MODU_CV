# 오픈스페이스 자리 알박기 감지 (지금자리)

사전학습된 YOLO(COCO)로 좌석 영역(ROI)마다 **사람**과 **물건**(가방, 노트북, 책, 컵 등)을 검출하고,
"최근 2시간 중 사람이 앉아 있던 시간의 비율"로 자리 알박기를 판정합니다.
사람이 누구인지는 식별하지 않으며, 영상도 저장하지 않습니다.

## 좌석 상태

| 상태 | 색 | 조건 | 학생에게 |
|---|---|---|---|
| 빈자리 | 초록 | 사람도 물건도 없음 | 이용 가능 |
| 사용중 | 파랑 | 사람이 있음 | 이용 불가 |
| 자리비움 | 노랑 | 물건만 있음, 재석 비율이 기준 이상 (화장실·식사 등) | 이용 불가 |
| 반납예정 | 주황 | 물건만 있음, 최근 2시간 재석 비율 10% 미만 → 15분 유예 카운트다운 | 이용 불가 |
| 반납대상 | 빨강 | 유예 15분이 지남 → 관리자가 물건을 보관함으로 이동 | 이용 가능 |

- **재석 비율로 판정하는 이유**: "2시간 연속 부재" 규칙은 1시간 50분마다 5분씩 들렀다 나가면 한 번도 걸리지 않습니다. 재석 비율은 이런 꼼수도 잡아냅니다.
- **처음 2시간은 판정 보류**: 짐을 두고 막 나간 사람을 바로 반납예정으로 만들지 않으려고, 자리에 물건이 생긴 뒤 2시간을 관찰한 후에만 판정합니다.
- **유예 중에 돌아오면** 사용중으로 바뀌고 자리는 유지됩니다.
- **가림 대응**: 사람이 30초 넘게 연속으로 안 보여야 "없음"으로 바꿉니다. 칸막이나 옆 사람에게 잠깐 가려지거나 검출을 놓쳐도 상태가 흔들리지 않습니다.
- **반납대상 자리에 새 사람이 앉으면** 새 이용자로 보고 기록을 처음부터 다시 쌓습니다.

기준값은 모두 `seats.json`의 `rules`에서 바꿀 수 있습니다 (단위: 초).

| 키 | 기본값 | 의미 |
|---|---|---|
| `window_sec` | 7200 | 재석 비율을 계산하는 기간 (2시간) |
| `min_ratio` | 0.10 | 이 비율 미만이면 반납예정 |
| `grace_sec` | 900 | 반납예정 → 반납대상 유예시간 (15분) |
| `person_on_sec` / `person_off_sec` | 3 / 30 | 사람 있음/없음으로 바뀌기 위한 연속 시간 |
| `item_on_sec` / `item_off_sec` | 5 / 60 | 물건 있음/없음으로 바뀌기 위한 연속 시간 |

## 설치

```bash
python -m venv .venv
.venv\Scripts\python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install ultralytics pytest
```

가중치(`yolo11s.pt`)는 처음 실행할 때 자동으로 내려받습니다.

## 사용법

### 1. 좌석 영역 지정

```bash
.venv\Scripts\python src\roi_editor.py --source 녹화영상.mp4 --out seats.json
```

웹캠이면 `--source 0`을 씁니다. `1_좌석지정.bat`을 실행해도 됩니다.
클릭으로 꼭짓점을 찍고 Enter(또는 우클릭)를 누르면 좌석 하나가 확정됩니다. 책상 위와 의자가 함께 들어가도록 그리세요.
`z`는 되돌리기, `s`는 저장, `q`는 종료입니다.
판정 기준은 `seats.example.json`의 `rules`를 `seats.json`에 복사해서 바꿉니다. 없으면 기본값을 씁니다.

### 2. 감지 실행

```bash
# 실시간 웹캠, 실제 기준 (2시간 / 10% / 15분)
.venv\Scripts\python src\run.py --source 0 --seats seats.json

# 녹화 영상으로 시연: 시간을 60배 압축 (2시간 → 2분, 15분 → 15초), 결과 영상 저장
.venv\Scripts\python src\run.py --source 녹화영상.mp4 --seats seats.json --time-scale 60 --save 결과.mp4
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--weights` | yolo11s.pt | 작은 물건을 놓치면 `yolo11m.pt`처럼 더 큰 모델을 씁니다 |
| `--imgsz` | 960 | 입력 크기. 좌석이 멀어 물건이 작게 보이면 1280으로 키웁니다 |
| `--conf` / `--person-conf` | 0.25 / 0.35 | 물건 / 사람 검출 신뢰도 기준 |
| `--fps` | 2 | 초당 분석 프레임 수 |
| `--time-scale` | 1 | 시연용 시간 압축 배율 |
| `--save` | 없음 | 결과 영상 저장 (사람은 모자이크) |
| `--no-show` | | 화면 창 없이 기록만 남김 |
| `--no-privacy` | | 화면의 사람 모자이크를 끔 (디버깅용) |

### 3. 남는 기록 (`logs/`)

- `presence.csv`: 10초마다 좌석별 `시각, 좌석, 사람(0/1), 물건(0/1), 상태, 재석비율`
- `events.csv`: 상태가 바뀐 순간. 반납 처리할 때 판정 근거로 씁니다.
- `status.json`: 현재 좌석 현황. 입구 화면이나 웹페이지에서 읽어 갈 수 있습니다.

## 검증

```bash
.venv\Scripts\python -m pytest -q
```

`tests/test_seat_logic.py`는 YOLO 없이 관측값만 넣어서 아래 시나리오를 확인합니다.
공부 중, 20초 가림, 화장실(10분), 가방만 두고 떠남, 유예 중 복귀, 5분씩 들르는 꼼수, 짐 챙겨 나감, 반납대상 자리에 새 학생 착석, 시간 압축.

## 앞으로 확인할 것 (Learning Issues)

- **기준 시간**: 실제로 얼마나 오래 자리를 비우는지 `presence.csv`로 며칠 모은 뒤 `window_sec`, `min_ratio`를 조정
- **가림**: 칸막이·옆 사람에게 가려지는 좌석은 `person_off_sec`를 늘리거나 카메라 각도를 바꿔서 테스트
- **작은 물건**: 책·펜 같은 작은 물건을 놓치면 `--imgsz 1280`, 더 큰 모델, 낮은 `--conf`를 시도
- **정확도**: 사람이 직접 센 결과와 `events.csv`를 비교해 판정 정확도 측정 (목표 90%)
