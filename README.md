| 폴더 | 내용 |
|---|---|
| [객체탐지_YOLO](객체탐지_YOLO) | YOLO 객체 탐지 실습(제조 데이터 탐지)과 YOLO를 활용한 틀린그림찾기 |
| [객체탐지_EfficientDet](객체탐지_EfficientDet) | EfficientDet 실습 코드 리뷰와 직접 해 보기 |

| [생성AI_StableDiffusion](생성AI_StableDiffusion) | Stable Diffusion 실습 |
| [생성AI_결함데이터생성](생성AI_결함데이터생성) | 생성형 AI로 제조 결함 데이터 생성 |
