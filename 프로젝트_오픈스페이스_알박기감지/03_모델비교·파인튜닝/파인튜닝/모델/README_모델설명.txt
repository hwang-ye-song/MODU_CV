이 문서는 사람이 읽어도 되고, AI 도구에 그대로 붙여 넣어 "이 모델을 내 코드에 붙여 줘"라고 시켜도 되게 썼습니다.


--------------------------------------------------------------
1. 한 줄 요약
--------------------------------------------------------------
사전학습 YOLO26s(COCO)를 우리 스터디룸 영상으로 추가 학습해서,
"사람(엎드린 사람 포함)"과 "테이블"을 원래 모델보다 훨씬 잘 잡게 만든 모델입니다.
클래스 번호와 이름은 COCO 80개 그대로라서, 기존 YOLO 코드에 파일만 바꿔 끼우면 됩니다.


--------------------------------------------------------------
2. 왜 만들었나
--------------------------------------------------------------
- 사전학습 YOLO는 천장 카메라 화면에서 테이블(dining table)을 잘 못 잡았습니다.
  (원본 YOLO26s: 1차.mp4 2%, 라즈베리파이 웹캠 영상 0%)
- 책상에 엎드린 사람도 모델에 따라 거의 못 잡았습니다. (원본 YOLO11s 6%, 원본 YOLO26s 92.9%)
- 알박기 판정에는 "사람이 자리에 있는지"와 "테이블 위치"가 핵심이라 이 둘을 고치려고 했습니다.


--------------------------------------------------------------
3. 왜 YOLO26s인가
--------------------------------------------------------------
같은 데이터·같은 설정으로 YOLO11s, YOLO26s, YOLO26m, YOLO26l을 모두 학습해 비교했습니다.

- 사람·테이블은 네 모델 모두 시험 영상에서 100%라 차이가 거의 없었습니다.
- 엎드린 사람은 YOLO26s가 100%로 YOLO11s(98.8%)보다 조금 높았습니다.
- m·l은 정확도 이득 없이 CPU 기준 2.5~3.5배 느리고 파일도 2배 이상 큽니다.
- 처리 구조는 "카메라 영상을 서버로 모아 한 번에 추론"입니다. YOLO26s는 서버 GPU(노트북 RTX 5060 기준)에서
  1장에 29ms(약 34장/초)라, 14개 룸을 2초마다 판정하는 데 필요한 초당 7장의 약 5배 여유가 있습니다.
- YOLO26은 엣지(CPU) 장치용으로 설계된 구조라, 나중에 룸별로 라즈베리파이에서 추론하는 방식으로 바꿀 때도
  그대로 쓰기 좋습니다. (이건 보조 근거이고, 정확도를 올린 건 구조가 아니라 우리 영상으로 한 파인튜닝입니다)


--------------------------------------------------------------
4. 무엇을 했나
--------------------------------------------------------------
[베이스 모델]
- yolo26s.pt (Ultralytics, COCO 사전학습)

[학습 데이터] 총 학습 637장 / 검증 90장
  (1) 휴대폰으로 테이블 주변을 돌며 찍은 영상 18초 → 3프레임마다 1장, 181장
      - 테이블 박스: 테이블을 잘 잡는 모델 4개(yolo11l, yolo11m, yolov9s, rtdetr-l)로 후보를 만든 뒤
        181장을 전부 눈으로 검수하고 틀린 것은 손으로 고침
      - 사람·물건 박스: yolov10s로 자동 라벨링
  (2) 스터디룸 천장 고정 카메라 영상(1차.mp4)의 앞 80% → 2초마다 1장
      - 카메라가 고정이라 테이블 위치가 안 변함 → 테이블 정답 박스 하나를 모든 프레임에 사용
      - 사람·물건 박스: yolov10s로 자동 라벨링
  (3) 위에서 찍은 엎드린 사람 사진 6장 (3번씩 복사해서 비중을 늘림)

[라벨링 규칙]
- 테이블은 물건이나 사람에 가려진 부분까지 포함해 테이블 전체를 박스로 그림
- 클래스 번호는 COCO 그대로 (0=person, 60=dining table 등)

[학습 설정]
- epochs 25, imgsz 960, batch 8, optimizer AdamW, lr0 0.001, 전체 학습(freeze 없음)
- 노트북 RTX 5060 Laptop에서 학습
- 처음에 사람 데이터 없이 테이블 위주로만 학습했더니 모델이 사람과 가방을 잊어버렸습니다
  (YOLO11s 기준 사람 100% → 68%, 가방 89% → 14%). 그래서 사람 데이터를 넣고 학습률을 낮춘 것이 v2입니다.

6. 한계 (꼭 알고 쓰기)
--------------------------------------------------------------
- 시험 영상은 실제 고정 카메라 화면이지만, 룸은 1곳입니다. 다른 룸에 설치하면 그 룸 카메라 화면으로 먼저 확인하고,
  안 되면 그 룸 영상을 추가해서 다시 학습해야 합니다.
- 엎드린 사람 시험은 1명, 7초 분량입니다. 다른 사람, 얼굴을 카메라 쪽으로 두고 엎드리기, 후드·모자 착용,
  조명 변화(저녁, 불 하나 끔) 등은 아직 안 봤습니다.
- 가방을 거의 못 잡습니다(웹캠 영상 0%). 사람·테이블 용도에는 상관없지만,
  "짐만 남은 자리"를 물건 검출로 판정하려면 이 모델로는 부족합니다.
- 사람·물건 라벨은 yolov10s 자동 라벨이라 그 모델의 실수도 일부 배웠을 수 있습니다.
  물건 종류를 정확히 세는 용도로는 쓰지 마세요.
- 웹캠 영상 한 장면에서는 사람 3명에 박스 3개, 테이블 1개로 중복 없이 나왔습니다.
  다만 다른 장면에서 중복 박스가 나올 수 있으니, 사람 수를 세기보다 좌석 영역별 "있다/없다"로 판정하세요.

8. 사용법
--------------------------------------------------------------
[가장 기본: 사람과 테이블만 검출]

from ultralytics import YOLO

model = YOLO("알박기_yolo26s_v2.pt")
results = model.predict("frame.jpg", imgsz=960, conf=0.25, classes=[0, 60], verbose=False)

for box in results[0].boxes:
    cls = int(box.cls)                  # 0 = 사람, 60 = 테이블
    name = results[0].names[cls]        # "person" 또는 "dining table"
    score = float(box.conf)
    x1, y1, x2, y2 = box.xyxy[0].tolist()
    print(name, round(score, 2), [int(x1), int(y1), int(x2), int(y2)])

# 웹캠 영상 한 장면에서 실제로 나온 결과
# person 0.95 [0, 26, 451, 604]
# person 0.93 [528, 0, 1001, 354]
# person 0.93 [218, 515, 669, 817]
# dining table 0.92 [136, 115, 1184, 821]

[웹캠이나 영상에 바로 쓰기]

import cv2
from ultralytics import YOLO

model = YOLO("알박기_yolo26s_v2.pt")
cap = cv2.VideoCapture(0)               # 웹캠 번호, 또는 "영상.mp4"
while True:
    ok, frame = cap.read()
    if not ok:
        break
    r = model.predict(frame, imgsz=960, conf=0.25, classes=[0, 60], verbose=False)[0]
    cv2.imshow("result", r.plot())
    if cv2.waitKey(1) == 27:            # ESC로 종료
        break

[권장 설정값]
- imgsz=960 : 학습과 같은 크기. 640으로 줄이면 빨라지지만 성능은 확인 안 함
- 사람 기준값 0.35 : 엎드린 사람도 이 기준에서 100% 잡힘
- 테이블 기준값 0.25 : 실제 신뢰도가 0.9 이상이라 0.5까지 올려도 여유 있음

[주의할 이름]
- 테이블 클래스 이름은 "table"이 아니라 COCO 이름 그대로 "dining table"(60번)입니다.
- 화면에 "공부 테이블"로 보이게 하려면 출력할 때만 이름을 바꾸세요.
    label = {"dining table": "study table"}.get(name, name)

from ultralytics import YOLO

# → 알박기_yolo26s_v2_ncnn_model 폴더가 생김

# 파이에서
model = YOLO("알박기_yolo26s_v2_ncnn_model")
model.predict("frame.jpg", imgsz=960, classes=[0, 60])

- 파이에서의 속도와, 변환 후에도 정확도가 그대로인지는 아직 확인하지 않았습니다.
