### 1. 설치

Python 3.10 이상이 필요합니다. NVIDIA GPU가 있으면 빠르고, 없어도 CPU로 돌아갑니다(CPU는 1장 약 135ms라 룸 7개 정도까지 1초 간격 판정).

```bash
git clone https://github.com/hwang-ye-song/MODU_CV.git
cd "MODU_CV/프로젝트_오픈스페이스_알박기감지/프로젝트_최종/통합 코드모음/06_통합실행"
pip install ultralytics opencv-python pillow
```

GPU를 쓰려면 [PyTorch 홈페이지](https://pytorch.org/get-started/locally/)에서 CUDA 버전 PyTorch를 먼저 설치하세요. 최종 모델(`03_모델/알박기_yolo26s_v2.pt`)은 저장소에 들어 있고, SAM(`sam2.1_t.pt`)과 기본 YOLO26s(`yolo26s.pt`)는 처음 실행할 때 자동으로 받습니다.

### 2. 웹캠으로 바로 써 보기

```bash
python 성능확인.py
```

1. 초록불 시간을 묻습니다. 시험할 때는 `00:00:20`(20초)처럼 짧게 넣으세요. `000020`처럼 6자리로 써도 되고, 그냥 Enter를 누르면 학교 규칙인 30분입니다.
2. 창에 사람 박스, 감지 범위, 지금 신호등 색이 실시간으로 나옵니다. 왼쪽 아래에는 판정 시간과 이 컴퓨터로 1초 간격 판정이 가능한 룸 수가 나옵니다.
3. 키: `q` 종료 · `m` 사람 모자이크 켜기/끄기 · `t` 판정 모델 바꾸기

- 테이블이 화면에 보이게 카메라를 두세요. 감지 범위를 테이블 위치로 자동으로 정합니다.
- 웹캠은 기본 YOLO26s로 시작합니다. 파인튜닝 모델은 천장에서 내려다본 사진으로 학습해서 정면 웹캠 앞 사람을 거의 못 찾습니다(14장 중 2장).

### 3. 여러 룸을 한 번에 판정하기 (통합 실행)

```bash
# 영상 하나를 룸 14개처럼 복제해 시험
python 알박기_실행.py --demo-video 내영상.mp4 --demo-rooms 14 --open

# 실제 운영: 룸 설정 파일로 카메라 여러 대
python 알박기_실행.py --rooms rooms.json --signal-url http://신호등주소/signal --limit 00:30:00
```

- `rooms.json`은 [rooms.example.json](통합%20코드모음/06_통합실행/rooms.example.json)을 복사해 룸마다 `id`와 `source`(RTSP 주소, 웹캠 번호 `"0"`, 영상 파일)를 적으면 됩니다. 룸별 신호등 주소는 `signal_url`로 따로 줄 수 있습니다.
- 천장에서 테이블이 보이게 찍은 영상이나 카메라를 쓰세요. 기본 판정 모델은 천장 각도에 맞춘 파인튜닝 v2입니다.
- `--open`을 붙이면 현황 화면이 준비되는 대로 브라우저가 열립니다.

### 4. 결과 확인

| 어디서 | 무엇을 |
|---|---|
| 브라우저 http://localhost:8800 | 룸 지도와 신호등 색, KPI, 선택한 룸의 실시간 카메라(사람 모자이크)와 판정 근거, 알림, 상태 기록 |
| `결과/판정기록.csv` | 모든 판정 기록 (시각, 룸, 상태, 신호등 색, 범위 안 사람·짐 수, 빈 책상 여부, 비운 시간) |
| `결과/스냅샷/` | 색이 바뀐 순간의 화면 (사람 모자이크, 1일 뒤 자동 삭제) |
| 신호등 | 색이 바뀌면 `{"room": "3층-1", "color": "green"}`을 POST로 보냄 |

### 자주 막히는 점

- **시연 영상(1차.mp4)이 없어요**: 팀원 얼굴이 나와 공개 저장소에 올리지 않았습니다. 직접 찍은 영상이나 웹캠을 쓰세요.
- **노랑이 안 보여요**: 사람이 10초 연속 안 보여야 부재로 보므로, 초록불 시간을 10초 이하로 하면 빨강에서 바로 초록이 됩니다. 20초 이상으로 넣으세요.
- **8800 포트를 이미 쓰고 있어요**: `--port 8801`처럼 다른 포트를 주세요.
- **처음 실행이 오래 걸려요**: SAM과 기본 YOLO 가중치를 내려받는 중입니다. 인터넷 연결이 필요합니다.
- 옵션 전체, 현황 화면 구성, 처리 속도 측정은 [06_통합실행 README](통합%20코드모음/06_통합실행/README.md)에 있습니다.

## 프로젝트 성과

- **문제**: 학교에는 "30분 넘게 비운 룸은 짐을 옮기고 써도 된다"는 규칙이 있지만, 방금 온 학생은 짐 주인이 언제 나갔는지 알 수 없어 규칙을 쓰지 못합니다.
- **해결**: 룸마다 천장 카메라 1대, 교내 PC 1대가 1초마다 판정해 문 위 신호등 색을 바꿉니다. 얼굴은 보지 않고 영상은 저장하지 않습니다.
- **고객과 기준**: 비용을 내는 고객은 학교 운영 담당, 매일 보는 사용자는 학생입니다. 모든 선택은 ① 정확도·속도 ② 비용 ③ 운영·유지보수 ④ 개인정보로 판단했습니다.

| 신호등 | 상태 | 학생 행동 |
|---|---|---|
| 🔴 빨강 | 감지 범위 안에 사람이 있음 | 사용 중 |
| 🟡 노랑 | 사람이 없고 30분 미만, 짐이 남아 있음 | 짐에 손대지 않음 |
| 🟢 초록 | 사람이 30분 넘게 없음 | 짐을 룸 앞 바구니로 옮기고 사용 |
| 🟢 초록 | 사람도 짐도 없는 빈 책상 | 기다리지 않고 바로 사용 |

| 결과 | 값 |
|---|---|
| 최종 모델 | YOLO26s 파인튜닝(v2), 학습 데이터 727장. 학습에 안 쓴 영상 기준 테이블 2% → 100%, 엎드린 사람 92.9% → 100% |
| 감지 범위 | SAM 테이블 테두리 +15%, 겹침 기준 10% (통로·옆방 오탐 방지, 사람이 있는데 비었다고 본 순간 0초) |
| 처리 속도 | GPU 1장 18.1ms (필요 71ms의 3.9배 여유), 룸 14개 한 바퀴 중앙값 453ms → 1초 간격 판정 가능 |
| 서버 사양 | 최소 GTX 1060급, 권장 GTX 1070급 + 라이젠 5 5600급 (약 50만 원) |
| 비용 | 초기 207만 원, 구독 룸당 월 1.5만 원 (연 252만 원 = ERICA 학생지원비의 0.02%) |
| 도입 효과 (시뮬레이션) | 저녁 식사 시간 룸 활성화율 22% → 50% |

## 한계와 다음 단계
