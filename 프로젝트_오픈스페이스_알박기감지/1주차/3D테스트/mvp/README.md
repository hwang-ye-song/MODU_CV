# 스터디룸 알박기 감지 MVP

기획서 최종안(룸 단위, 30분 규칙, 3색 표시등)대로 동작하는 발표용 최소 구현입니다.

## 동작 방식

1. 사전학습 YOLO(COCO)로 **테이블(dining table)**과 **사람(person)**을 검출합니다. 추가 학습은 없습니다.
2. 가장 큰 테이블 박스를 가로·세로 **30% 넓혀** 감지 영역으로 씁니다. 감지 영역은 손으로 그리지 않습니다.
3. 감지 영역 안에 사람이 있으면 🔴 사용중, 없으면 부재 시간을 셉니다.
   - 30분 미만: 🟡 자리비움 (화면에 "초록불까지 남은 시간" 표시)
   - 30분 이상: 🟢 이용가능 (짐은 바구니로 옮기고 사용)
4. 사람이 10초 넘게 안 보여야 "없음"으로 바꿔서, 잠깐 가려져도 상태가 흔들리지 않습니다.
5. 화면과 결과 영상에서 사람은 모자이크하고, 영상은 저장하지 않는 것이 기본입니다. `logs/`에는 상태가 바뀐 시각만 남습니다.

## 실행

```bash
# 녹화 영상으로 시연 (30분 → 30초로 압축), 결과 영상 저장
.venv\Scripts\python mvp\run.py --source 시연영상.mp4 --time-scale 60 --save 결과.mp4

# 웹캠 실시간 (실제 30분 기준)
.venv\Scripts\python mvp\run.py --source 0
```

`3_MVP_실행.bat`을 실행하면 웹캠으로 바로 시연 모드가 켜집니다. 영상 파일을 bat 위에 끌어다 놓아도 됩니다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--time-scale` | 1 | 시연용 시간 압축 (60이면 30분 → 30초) |
| `--limit-min` | 30 | 초록불 기준 (분) |
| `--expand` | 0.30 | 테이블 박스를 넓히는 비율 |
| `--zone x1,y1,x2,y2` | 없음 | 테이블이 안 잡히는 룸에서 감지 영역을 직접 지정 |
| `--save` | 없음 | 결과 영상 저장 (사람 모자이크) |
| `--room` | 3층-1 | 화면에 표시할 룸 이름 |

## 테스트

```bash
.venv\Scripts\python -m pytest mvp -q
```

공부 중, 8초 가림, 나간 뒤 29분(노랑)과 30분(초록), 돌아오면 초기화, 시작부터 빈 룸, 시연용 압축까지 6가지를 확인합니다.

## 시연 영상 찍는 법

- 카메라(폰)를 **룸 안 높은 곳**에서 테이블 전체가 보이게 고정합니다. 유리 밖에서 찍으면 바깥 테이블이 잡힐 수 있습니다.
- 순서: 앉아서 공부 20초 → 짐을 두고 나감 → 40초 이상 대기 → (선택) 다른 사람이 들어와 짐을 옮기고 앉음
- `--time-scale 60`이면 나가고 30초 뒤에 초록불이 켜집니다.

## 3D 디지털 트윈 시뮬레이션 (`mvp/twin/index.html`)

두 가지로 실행할 수 있습니다. 둘 다 three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

| 실행 파일 | 판정 방식 | 주소 |
|---|---|---|
| `5_3D_YOLO시뮬레이션.bat` (권장) | 룸마다 천장 카메라 화면을 렌더링해 **YOLO11s로 실제 검출**한 결과로 신호등 판정 | http://127.0.0.1:8766/ |
| `4_3D시뮬레이션.bat` | 3D 좌표로 박스를 그려 판정 (YOLO 없이 가볍게) | http://127.0.0.1:8765/?noyolo=1 |

- 융합교육관 스터디룸 14개(3층 6개, 4층 오픈형 6개, 독립형 2개)를 3D로 배치했습니다.
- 가상 학생이 들어와 공부하다가 짐을 두고 나가면 문 앞 신호등이 🟡로, 30분이 지나면 🟢로 바뀝니다. 다른 학생이 🟢 룸에 오면 짐을 회색 바구니로 옮기고 앉습니다.
- 오른쪽 패널에 지금 룸 활성화율, 19시부터의 평균 활성화율, 30분 넘게 짐만 있는 룸 수, 짐 정리 후 다시 쓰인 횟수가 실시간으로 나옵니다.
- **감지 시스템 끄기** 버튼을 누르면 기존 방식(언제부터 비었는지 모름)으로 돌아가, 짐만 있는 룸 앞에서 학생들이 돌아서는 모습을 비교할 수 있습니다.
- **1층 현황판** 버튼을 누르면 2027년에 설치할 현황판 화면을 미리 볼 수 있습니다.
- 판정 규칙은 `room_logic.py`와 같습니다 (사람이 있으면 빨강, 없으면 30분까지 노랑, 이후 초록).

### 천장 카메라 + YOLO 연결 (`5_3D_YOLO시뮬레이션.bat`)

- 사람은 머리(피부·머리카락·눈·코·귀), 목, 몸통(옷), 어깨·팔꿈치가 있는 팔, 다리를 가진 절차적 3D 모델입니다. **앉아서 공부**, **엎드려 잠**, **걷기** 자세가 있고 옷·머리 색, 체격, 긴 머리·후드가 사람마다 다릅니다. 옷과 머리카락에는 절차적으로 만든 결·주름 무늬를 입혔습니다 (외부 모델·이미지 파일 없음).
- 룸마다 안쪽 모서리 높이 2.1 m에 CCTV를 두고(시야각 72°, 960×720), 비스듬히 내려다본 화면을 따로 렌더링해 JPEG로 `mvp/twin/yolo_server.py`에 보냅니다.
- 서버는 `mvp/detector.py`의 `RoomDetector`를 그대로 쓰며, 룸마다 인스턴스를 따로 둡니다(테이블 이동 평균 때문). 테이블 박스, 30% 감지 영역, 사람 박스와 신뢰도, 영역 안 사람 수를 돌려줍니다.
- **3D 화면에서 룸을 클릭**하거나 오른쪽 목록에서 고르면, 그 룸 카메라 화면과 YOLO 결과(흰 박스 테이블, 상태색 감지 영역, 사람 박스와 신뢰도, 영역 안 사람 수)가 오른쪽 "천장 카메라" 창에 초당 4~5장으로 갱신되고, 3D에는 그 카메라의 시야(하늘색 사각뿔)가 표시됩니다. 선택한 룸을 3번 중 2번 검출하고, 나머지 룸은 돌아가며 검출합니다.
- 테이블을 못 찾으면 화면 전체를 감지 영역으로 쓰며, 카메라 창에 점선으로 표시합니다.
- 서버가 없거나 응답이 끊기면 자동으로 좌표 기반 판정으로 바뀌고, 카메라 창 위에 "YOLO 연결됨 / 미연결"이 표시됩니다. **판정** 버튼으로 직접 바꿀 수도 있습니다.
- YOLO 판정 때 사람 있음/없음 디바운스는 시뮬레이션 시간으로 1분/5분입니다(`room_logic.py`의 2초/10초에 해당).
- 실제처럼 유리벽에는 무릎 위부터 반투명 필름을 붙였고 문은 닫혀 있습니다. 3D 전체 화면에서는 안이 보이도록 반투명하게, 카메라 렌더에서는 불투명하게 그립니다(옆 룸 사람이 카메라에 잡히지 않게).

| 서버 옵션 | 기본값 | 설명 |
|---|---|---|
| `--person-conf` | 0.35 | 사람 신뢰도 기준 (페이지 주소에 `?conf=0.3`을 붙여 요청마다 바꿀 수도 있음) |
| `--table-conf` | 0.15 | 테이블 신뢰도 기준 (3D 렌더에서 0.25는 테이블을 자주 놓쳐 낮춤) |
| `--imgsz` | 960 | YOLO 입력 크기 |
| `--port` | 8766 | 포트 |

### 검출률 측정 (실측, 2026-10-15)

`eval_yolo.py`로 정해진 장면 8세트 × 14개 룸 = 112장을 헤드리스 Edge에서 렌더링하고 YOLO11s(imgsz 960, person_conf 0.35)를 돌렸습니다. 정답 박스는 3D 모델을 카메라에 투영한 것이고, 화면에 절반 이상 들어온 사람만 셌습니다.

```bash
.venv\Scripts\python mvp\twin\yolo_server.py --capture-dir mvp\twin\_captures   # 창 하나
.venv\Scripts\python mvp\twin\eval_yolo.py --collect --trials 8                 # 다른 창
```

| 자세 | 사람 수 | 검출 | 검출률 | 평균 신뢰도 |
|---|---:|---:|---:|---:|
| 앉아서 공부 | 163 | 160 | 98.2% | 0.77 |
| 엎드려 잠 | 88 | 43 | 48.9% | 0.67 |
| └ 등이 카메라 쪽 | 44 | 29 | 65.9% | 0.69 |
| └ 얼굴이 카메라 쪽 (머리·팔만 보임) | 44 | 14 | 31.8% | 0.61 |
| 걷는 중 | 44 | 33 | 75.0% | 0.77 |
| 전체 | 295 | 236 | 80.0% | 0.75 |

- 테이블(dining table ≥ 0.15): 112장 중 68장 검출, 위치까지 맞은 것 65장. 테이블을 한 번도 못 찾아 화면 전체를 감지 영역으로 쓴 장면 3장.
- 룸 판정(감지 영역 안 사람 1명 이상): 사람 있는 룸 75/84, 빈 룸 28/28 → 정확도 92.0%.
- 개선 과정: 처음 모델(알약 모양 몸통, 무늬 없는 옷)은 앉은 사람 46.3%, 엎드린 사람 10.2%, 걷는 사람 17.4%였습니다. 옷·머리카락 무늬를 넣은 것이 가장 효과가 컸고(앉은 사람 100%, 엎드린 사람 61.4%, imgsz 640 기준), 시야각을 넓히고 카메라를 벽 높이 아래로 내리고 반투명 필름을 붙여 옆 룸 오검출을 줄였습니다.
- 실제 사진과 비교: 융합교육관에서 찍은 엎드린 사람 사진 6장(`실험_엎드린사람/결과.md`)은 YOLO11s가 6/6 모두, 평균 0.85로 잡았습니다. 3D 모델의 엎드린 자세는 48.9%로 **실제보다 많이 낮습니다.** 특히 카메라를 마주 보고 엎드려 머리와 팔만 보이는 경우를 잘 못 잡습니다. 3D 결과는 모델 형태의 한계로 보고, 실제 성능은 실사진 실험을 기준으로 보는 것이 맞습니다.
