# 오픈스페이스 알박기 감지 시스템

한양대 ERICA 융합교육관 스터디룸 14개에서 짐만 두고 30분 넘게 자리를 비운 룸을 카메라로 찾아, 문 위 신호등 색으로 알려 주는 B2B 서비스입니다. 팀 '알박기 척결'에서 총괄·기획·발표를 맡았습니다.

> 문서는 생성형 AI(Claude)를 활용해 작성자의 아이디어와 답변을 정리했습니다. 실제 사람이 나오는 이미지는 모두 모자이크했습니다.

## 한눈에 보기

- **문제**: 30분 자리 비움 규칙은 있지만, 방금 온 학생은 짐 주인이 언제 나갔는지 알 수 없어 규칙을 쓰지 못합니다.
- **해결**: 룸마다 천장 카메라 1대, 교내 PC 1대가 1초마다 판정해 문 위 신호등 색을 바꿉니다. 얼굴은 보지 않고 영상은 저장하지 않습니다.
- **고객과 기준**: 고객은 학교 운영 담당, 사용자는 학생. 모든 선택은 ① 정확도·속도 ② 비용 ③ 운영·유지보수 ④ 개인정보로 판단했습니다.

| 신호등 | 상태 |
|---|---|
| 🔴 빨강 | 감지 범위 안에 사람이 있음 |
| 🟡 노랑 | 사람이 없고 30분 미만, 짐이 남아 있음 |
| 🟢 초록 | 사람이 30분 넘게 없음 → 짐을 바구니로 옮기고 사용 |
| 🟢 초록 | 사람도 짐도 없는 빈 책상 → 바로 사용 |

| 결과 | 값 |
|---|---|
| 최종 모델 | YOLO26s 파인튜닝(v2): 테이블 2% → 100%, 엎드린 사람 92.9% → 100% (학습에 안 쓴 영상 기준) |
| 처리 속도 | GPU 1장 18.1ms, 필요 71ms의 3.9배 여유 · 최소 GTX 1060급 |
| 비용 | 초기 207만 원, 구독 룸당 월 1.5만 원 (연 252만 원 = 학생지원비의 0.02%) |

## 진행 요약

- **10/15 1차 회의**: 역할과 구현 방향을 정하고 판정 코드(MVP)를 만들었다. 엎드린 사람 사진 6장으로 모델 6종을 즉석 검증했다.
- **10/17**: 3D 시뮬레이션에서 엎드린 사람이 48.9%로 실제(6/6)와 달라 중단하고, 실제 룸 영상 검증으로 바꿨다.
- **10/18**: 사전학습 16종 중 테이블과 엎드린 사람을 둘 다 잡는 모델이 없어, 학습 데이터 727장을 직접 만들어 파인튜닝했다. 1차 학습은 사람을 잊어(100% → 68%) v2로 다시 학습했다.
- **10/20~21**: B2B 방향으로 비용과 학교 예산을 계산하고, 실측으로 서버 최소 사양을 정했다. 사각형 박스가 통로까지 덮는 문제를 SAM 테두리 +15%와 겹침 기준 10%로 해결했다. 라즈베리파이(1장 2.8초, 81.3°C)와 클라우드 GPU는 검토 후 제외했다.
- **10/21 2차 회의**: 팀원 실험 결과를 통합하고, 발표 슬라이드를 팀원 피드백으로 수정했다. MVP 관리자 대시보드를 만들었다.
- **10/22**: 리허설 녹음으로 발표문을 다듬고, 빈 책상은 바로 초록이 되도록 판정 규칙을 바꿨다. 최종 발표.

학교 협조(카메라 설치, 운영 승인, 개인정보 검토) → 실제 룸 7일 수집 → 현장 데이터로 재학습 → 시험 합격 시 14개 룸 적용. 불합격 기준은 관찰 300회 중 잘못된 초록 1건 이상, 또는 빈 룸 놓침 2% 초과입니다.
