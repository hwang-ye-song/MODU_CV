# 오픈스페이스 알박기 감지 시스템

한양대 ERICA 융합교육관 스터디룸 14개에서 짐만 두고 30분 넘게 자리를 비우는 알박기를 감지해 문 앞 표시등으로 알려 주는 프로젝트입니다.

> 문서는 생성형 AI(Claude)를 활용해 작성자의 아이디어와 답변을 정리하고 보기 좋게 편집했습니다.

## 핵심 요약

- **문제**: 저녁 시간대 스터디룸 14개 중 절반 이상이 짐만 남은 채 1시간 넘게 비어 있다. 30분 자리 비움 규칙은 있지만, 언제부터 비었는지 확인할 방법이 없어 아무도 짐을 치우지 못한다.
- **해결**: 룸마다 카메라를 달고, YOLO가 사전학습한 테이블과 사람 클래스로 룸 안에 사람이 있는지만 확인한다. 얼굴은 식별하지 않고 영상도 저장하지 않는다.
- **목표**: 30분 넘게 짐만 있는 룸 0개, 저녁 시간대 룸 활성화율(사람이 실제로 있는 룸의 비율) 50% 이하 → 80% 이상

## 판정 규칙

| 표시등 | 상태 | 학생 행동 |
|---|---|---|
| 🔴 빨강 | 사람 있음 | 사용 중 |
| 🟡 노랑 | 사람 없음, 30분 미만 | 짐에 손대지 않음 |
| 🟢 초록 | 사람 없음, 30분 이상 | 짐을 룸 앞 회색 바구니로 옮기고 사용 |

## 진행 요약

**1주차**
- **10/15 (1차 회의)**: 역할과 구현 방향을 정하고, 판정 코드(MVP)를 만들었다. 엎드린 사람 사진 6장으로 모델 6종을 검증해 모두 검출했고, 속도와 크기를 비교해 YOLO11s를 기본 모델로 정했다. 3D 디지털 트윈도 만들었다.
- **10/16**: 실제 스터디룸 영상을 분석해 사람 없이 노트북·가방만 있는 장면이 잡히고, 룸 공용 테이블은 0.63~0.71로 검출되는 것을 확인했다.
- **10/17**: 역할을 확정하고 1차 회의 보고서를 작성했다. 3D 사람 모델로는 엎드린 사람이 48.9%로 실제와 달라 시뮬레이션은 중단하고 실제 영상 검증으로 바꿨다.

**2일차**
- **10/18**: 라즈베리파이 웹캠 영상으로 YOLO 16종을 비교했지만, 테이블과 엎드린 사람을 둘 다 잘 잡는 모델이 없었다. 학습 데이터 727장을 직접 만들어 파인튜닝한 결과, YOLO26s v2가 학습에 안 쓴 영상에서 테이블·사람·엎드린 사람을 모두 100% 잡아 최종 모델로 정했다. 카메라 영상을 서버로 모아 한 번에 처리하는 구조로 결정했다.
